# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, send an email to **sessionplan@timjpeters.com**.

Please include:

- A description of the vulnerability
- Steps to reproduce or a proof-of-concept
- Potential impact
- Any suggested fixes (if applicable)

You should receive a response within **72 hours**. If the issue is confirmed, a fix will be released as soon as possible depending on complexity. You'll be kept informed of progress and credited in the release notes (unless you prefer to remain anonymous).

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest release | ✅ |

The `main` branch receives security fixes. Older versions are not supported.

## Scope

This policy covers the Sessionplan frontend application and any bundled server-side code included in this repository. It does not cover the hosted instance at sessionplan.de, which may have its own infrastructure-level protections.
